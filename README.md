## F5 Journeys Repository Move

The F5 Journeys migration utility was previously hosted on GitHub. As of Journeys version 4.2.0, the tool is now distributed exclusively through the MyF5 Downloads portal:

    Go to [MyF5 Downloads](https://my.f5.com/manage/s/downloads).
    For Group select BIG-IP.
    For Product Line select F5 Journeys App.
    For Product Version select the latest version.
    Complete the remaining steps to download a file to your workstation.

For other F5 community content, head to <https://community.f5.com>.
